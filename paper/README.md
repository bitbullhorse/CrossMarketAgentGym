# SoftwareX paper materials

This directory contains editable paper source material, not a claim that every planned experiment
has been executed.

- `softwarex-paper-outline.md` is the article structure and draft technical narrative.
- `artifact-map.md` maps manuscript claims, tables, figures, and reproducibility evidence.
- Phase 8 generates the current tables and figures with:

  ```bash
  cmag report softwarex --config configs/reporting/softwarex.yaml
  ```

Cross-stock zero-shot, leave-one-market-out, and publication-scale multi-seed ablations remain
planned or partial. They must not be described as complete until dedicated locked evidence exists.

Author names, affiliations, acknowledgements, funding, conflicts, and the Zenodo DOI require human
confirmation before submission and are intentionally not fabricated here.

# Lightweight sample checkpoint

`equal_weight_policy.json` is a deterministic, model-independent baseline checkpoint for the
four synthetic sample assets. It contains no learned parameters and used no training or
restricted financial data. Its purpose is to demonstrate a portable checkpoint artifact without
requiring PyTorch or Stable-Baselines3.

Verify the adjacent `equal_weight_policy.json.sha256` before use. This artifact is not a
trained trading recommendation.

# CrossMarketAgentGym benchmark-v1

This directory is a write-once Phase 13 snapshot generated only from the frozen Phase 12 formal matrix. It must never be overwritten. Create `benchmarks/v2` for a revised protocol or reviewer-requested experiment.

Large trades, weights, and checkpoints are represented by immutable path/size/SHA-256 indexes; small metrics, statistical results, Agent Replay, and HPO audit evidence are included directly.
